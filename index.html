Reliability-aware Machine Learning • EEG • Safety-Critical AI

I build failure-aware machine learning for high-stakes healthcare systems. My current focus is mitigating high-confidence errors in EEG-based sleep stage classification through risk-aware routing, robustness, and failure-mode analysis.

I am also interested in the longer-term direction of mechanistic digital twins and closed-loop intervention, connecting trustworthy perception to stable control.

Research

Mitigating High-Confidence Errors in Sleep Stage Classification (EEG)

Dec 2025 – Present
  • • Two-stage reliability pipeline (Transformer + feature-based expert) for clinical algorithm hardening.
  • • Risk-aware routing via cross-model disagreement (label mismatch + distributional divergence).
  • • 20-fold LOSO on Sleep-EDF-20: identified 1,923 HCEs; escalated 18.8% while reducing accepted-sample HCE rate to 1.62% (~64.4% reduction).
EEG Reliability Risk-aware routing

Two-Stage Voting for Suicide Risk Detection on Social Media

Apr 2025 – Present
  • • Length-confidence routing using a fine-tuned BERT classifier; filters 67.6% of inputs for cost-efficient uncertainty handling.
  • • Stage-2 ensembles: (i) BERT + LLM agent voting for recall, (ii) ML voting over LLM-extracted psychological features for interpretability.
  • • Strong cross-domain generalization; performance gap <2%.
