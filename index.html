Research

Selected projects with measurable outcomes and system-level framing.

Mitigating High-Confidence Errors in Sleep Stage Classification (EEG)

Dec 2025 – Present

A two-stage reliability pipeline for clinical algorithm hardening, using disagreement-based signals to identify and reroute high-risk samples.

  • • Dual-expert pipeline (Transformer + feature-based expert) for failure-aware inference.
  • • Routing via cross-model disagreement (label mismatch + distributional divergence).
  • • 20-fold LOSO (Sleep-EDF-20): identified 1,923 HCEs; escalated 18.8% while reducing accepted-sample HCE rate to 1.62% (~64.4% reduction).
EEG Reliability Uncertainty Risk-aware routing

Two-Stage Voting for Suicide Risk Detection on Social Media

Apr 2025 – Present

A cascaded system that handles “easy explicit” cases cheaply while reserving heavier reasoning for ambiguous content, improving cost-efficiency under uncertainty.

  • • Length-confidence routing with a fine-tuned BERT classifier; filters 67.6% of inputs.
  • • Stage-2 ensembles: (i) BERT + LLM agent voting (recall), (ii) ML voting over LLM-extracted psychological features (interpretability).
  • • Strong cross-domain generalization; reduced cross-domain gap to <2%.
NLP BERT Agents Interpretability

Control-Aware Neural Network Pruning for Real-Time CPS Deployment

Sep 2023 – Jul 2025

A pruning framework that incorporates system-level constraints, targeting real-time deployment while maintaining closed-loop safety guarantees under simulation.

  • • Modular PyTorch-based pruning pipeline for resource-constrained deployment.
  • • Integrated closed-loop safety constraints into the optimization objective.
  • • Achieved up to 148× acceleration while preserving system-level safety guarantees.
